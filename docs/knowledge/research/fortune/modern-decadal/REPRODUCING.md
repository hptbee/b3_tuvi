From the repository root, explicitly run `node docs/knowledge/research/fortune/modern-decadal/reproduce-evidence.mjs`. This new portable wrapper copies immutable fixture inputs to a temporary directory and adapts only absolute paths in an ephemeral copy of the original reviewed replay script. It executes existing B3 natal code and independent arithmetic; no upstream iztro source is imported, installed or executed. Original source, script and model response bytes remain unchanged. The original generator is retained for provenance; its absolute task paths are not portable without inspection.

The source bundle remains PROPOSED_NOT_APPROVED with null approval as immutable review input. Actual judgments, execution identities and comparator-derived decision are separate files. Public prose, historical authentication and classical/default profile approval remain withheld.
