# Core fixture evidence

Fixtures are hand-derived arithmetic under the experimental product specification, **not expert-verified golden cases** or scientific validity evidence.

JSON: `backend/test/fixtures/numerologyCore.json` (input, explicit expected metrics and derivation). Runner: `backend/test/numerologyCore.test.mjs`, registered in backend unit tests and the repository's fixture classification document.

Named cases include Nguyễn Văn An (48 total, vowels10, consonants38), Đỗ (D4/O6), Y-as-consonant LY, no-consonant AE, actual birth-date master11/22/33 and all-digits vs component-method divergence. Negative and property checks cover NFC/NFD, all 26 letter values, names with unsupported/hidden characters, valid century leap dates, future dates and bounds, optional names, reduction idempotence and input immutability.

Expected numbers are not generated by the calculator under test. Updating a semantic answer requires reviewing the versioned specification and its derivation; a failing test is not permission to change a formula or claim source verification.
