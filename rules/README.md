# Portable B3 rules (product copy)

These markdown files are **copies of portable rules** from the B3 system repository (`B3_HOME`). They apply when this product is attached to B3 (see root [AGENTS.md](../AGENTS.md)).

Some references use **`{B3_HOME}/docs/...`**. Those paths live in the **B3 system repository**, not under this product’s `docs/` tree. Resolve `B3_HOME` per AGENTS.md (for example `.b3/cloud-home` on Linux cloud agents).

Do not duplicate B3’s `precedence.md` or `research-methodology.md` into this product’s `docs/` tree unless an explicit, reviewed migration moves that policy here.
